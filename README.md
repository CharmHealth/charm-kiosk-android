# Kiosk India Android

Tablet-based healthcare kiosk for patient check-in and front-desk management.

- **Package**: `com.charm.ehr.kiosk`
- **Min SDK**: 24 (Android 7.0) · **Target / Compile SDK**: 36
- **Stack**: Kotlin 2.2.20, Jetpack Compose, Hilt, MVI + Clean Architecture
- **Sign-in**: CharmAuth SDK (CHIS / Auth0), git submodule `native/charm-mobile-auth-sdk` — see [docs/setup.md](./docs/setup.md#7-sign-in-charmauth-sdk)
- **Device support**: Large and extra-large tablets only — phones are not supported.

## Quick start

> **Before you build:** place two config files in `app/` — the first build will fail without them.
> - `google-services.json` — download from Firebase using the `charmhealthapps@gmail.com` account.
> - `apptics-config.json` — download per project from **Apptics > Settings > Application IDs**.
>
> - `secure.properties` (project root) — sign-in configuration; copy `secure.properties.example`.
>
> (`local.properties` is auto-generated by Android Studio.) See [docs/setup.md](./docs/setup.md) for details.

Replace `<your_repo_username>` with your Zoho repository username:

```bash
git clone --recurse-submodules https://<your_repo_username>@zrepository.zoho.com/medicalmine/charm/Mobile_Team/kiosk-india-android.git
cd kiosk-india-android
./gradlew installDebug
```

> **Build machines (including CI)** need read access to GitHub
> (`github.com/CharmHealth/charm-mobile-auth-sdk`) as well as zrepository: the CharmAuth SDK is a
> git submodule built with the app. Clone with `--recurse-submodules`, or run
> `git submodule update --init` in an existing clone; without it the build fails.

## Overview

Kiosk India Android is a Jetpack Compose tablet application for healthcare facilities. Patients use it for self check-in, health questionnaires, profile updates, and telehealth services. Front-desk staff use the same app for patient management — searching records, adding patients, and switching facilities.
